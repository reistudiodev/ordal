# DB Client

A native, cross-platform database client (think DBeaver / Beekeeper Studio).

- **Rust core** (`core/`): all logic: connections, drivers, queries, schema browsing.
- **Swift bindings** (`swift/`): generated by [UniFFI](https://mozilla.github.io/uniffi-rs/), shared by every app.
- **Native UI per platform** (`apps/`): SwiftUI on macOS, WinUI on Windows, GTK on Linux.

```
.
├── Cargo.toml              Rust workspace
├── core/                   dbclient-core crate (the brain)
│   ├── src/lib.rs          public API exported to Swift
│   └── uniffi.toml         Swift module names
├── uniffi-bindgen/         tiny CLI that generates the Swift bindings
├── swift/                  Swift package "DBClientCore"
│   ├── Sources/DBClientCoreFFI/   C header + module map (generated)
│   ├── Sources/DBClientCore/      Swift API (generated)
│   └── lib/                       Rust static lib goes here (build output)
├── apps/
│   ├── macos/              SwiftUI app
│   ├── windows/            placeholder (WinUI later)
│   └── linux/              placeholder (GTK later)
├── scripts/                build-core.sh, build-core.ps1, package-macos.sh
└── .vscode/                tasks, debug configs, recommended extensions
```

## Prerequisites

| | Rust | Swift |
|---|---|---|
| macOS | [rustup](https://rustup.rs) | `xcode-select --install` (Command Line Tools; full Xcode not needed) |
| Windows | rustup (MSVC toolchain) | [Swift for Windows](https://www.swift.org/install/windows/) + Visual Studio Build Tools |
| Linux | rustup | [Swift for Linux](https://www.swift.org/install/linux/) |

VS Code extensions are listed in `.vscode/extensions.json`; VS Code will offer to install them.

## Build and run

```sh
# 1. Build the Rust core, regenerate bindings, copy the static lib into swift/lib
./scripts/build-core.sh            # Windows: .\scripts\build-core.ps1

# 2. Run the app for your platform
cd apps/macos && swift run         # or apps/linux, apps\windows
```

In VS Code: **Terminal → Run Task → Run app**, or press F5 to debug.

Rust tests: `cargo test`. Swift tests: `cd swift && swift test` (after step 1).

## Do I need Xcode on the Mac?

No for day-to-day work. The Command Line Tools include the Swift compiler and the macOS SDK
(SwiftUI, AppKit), so everything builds and runs from VS Code. `scripts/package-macos.sh`
even makes a `.app` bundle without Xcode.

You'll want full Xcode only for: SwiftUI previews, asset catalogs / app icons,
App Store submission, or if you prefer Xcode's UI for signing.

## Adding to the core

1. Write Rust in `core/src/` and mark the API with `#[uniffi::export]`
   (functions, `impl` blocks) or derive `uniffi::Record` / `Enum` / `Object` / `Error`.
2. Run `scripts/build-core.sh`. The Swift side picks up the new API automatically.

Never edit `swift/Sources/DBClientCore/DBClientCore.swift` or the FFI header by hand: they are regenerated.
Hand-written Swift helpers go in new files next to them.
